Credits

XSIC is built as an operational XRPL console. This page clarifies where data comes from, what technology is used, and who maintains the service.

Data sources

  • XRPL ledger/network endpoints and related market-state interfaces consumed by XSIC server functions.
  • Project-managed derived snapshots and cached summaries where explicitly displayed as such.
  • Timestamp/state labels in each app should be treated as the primary freshness signal for operational use.

Technology stack

  • Vanilla HTML/CSS/JavaScript front-end with shared UI/navigation modules.
  • Serverless API/function layer for XRPL data retrieval, normalization, and response shaping.
  • Package-manifest dependencies and XRPL ecosystem tooling documented in this repository.

Operations and maintenance

  • Maintained by Badjoke-lab.
  • Release priorities: reliability, clarity, and safe interpretation of model outputs.
  • Feedback and bug reports are reviewed with reproducibility details (URL, timestamp, pair/preset, state label).
