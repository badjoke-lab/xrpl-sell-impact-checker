FAQ

Why can't I set currency = XRP?

XRP is the settlement asset. This tool estimates selling an IOU token into XRP, so you must provide an IOU (currency + issuer).

Is this financial advice?

No. This is an informational tool and provides estimates only.

Why can results differ from a DEX?

Ledger state changes constantly. Offers/AMM liquidity can change between reads and execution.
