What this tool does

XSIC estimates how selling an IOU token into XRP may impact price/liquidity on XRPL.

Data sources

  • CLOB (Order Book Offers) via XRPL JSON-RPC
  • AMM pool info via XRPL JSON-RPC

Key notes

  • XRP is the settlement asset. You must enter an IOU token (currency + issuer).
  • Results are estimates. Network conditions and on-ledger changes can differ.
  • Limits and pagination may cap how much depth we can read per request.
